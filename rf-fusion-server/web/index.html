SNOOPY RF fusion picture

Passive Wi-Fi/BLE survey devices stream their observations to one server, which merges them across devices into a coherent picture. This page is the live view. A browser cannot scan RF itself, so the sensing is done by SNOOPY devices (or any client POSTing the observation JSON to /observe). Run the server with --demo to populate it.
